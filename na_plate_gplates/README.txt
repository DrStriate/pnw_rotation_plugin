Source of North American Plate data for YHS. Code mostly generated by Gemini. 

Gemini/Google exchange captured (mostly) in the Geology/Siletzia/AI folder under "Google - GPlate data access NA Poles.docx"

Files
- plate_models.py - standalone program to pull summary data on Na plate and yhs from gplates
- plate_models_1Ma_res.py - preprocessing code to download from gplates data and create 1Ma files
- read_yhs_Location.py - runtime code to read yhs location from 1ma files pulled and processed from gplates
- test_main - standalone test for a single point using above runtime method and 1ma Muller data
